# Evaluation library

Install this local package in a separate environment. It contains WarBias
metrics, input validation and model collection support.

```sh
python -m pip install -e .
python -m pytest tests -q
```

This package includes components of the [Language Model Evaluation Harness](https://github.com/EleutherAI/lm-evaluation-harness).
Keep its [MIT license](LICENSE.md).
